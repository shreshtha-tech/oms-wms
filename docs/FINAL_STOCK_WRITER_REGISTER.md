## Direct-write search result

Source search across `inventory/`, `api/`, `scripts/` and `db/migrations/` for `ci_inventory_balance`, `ci_inventory_event`, `ci_reservation`, ledger calls, stock adjustment/transfer/receipt and Mongo quantity fields found the ledger as the only reviewed runtime code that directly updates physical columns or reservation status. `inventory/central-api.js` also inserts a zero balance row before calling the ledger in its transaction. Some `scripts/verify-*.mjs` files insert test balances directly; those are disposable fixture setup, **not** authorized runtime writers. Migrations define tables/triggers and notifications; they do not constitute business stock opening events. This search does not prove absence of dynamically assembled SQL, generic Mongo fields, external jobs or deployed code outside the repository.
