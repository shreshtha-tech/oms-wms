# Industry repository catalog

Reviewed 2026-10-09 against public repository source, tests and license files. Repository metadata is a point-in-time snapshot; activity and license boundaries can change. This is a source-reading catalog, not a security audit or recommendation to replace OMS/WMS.

## Project baseline used for fit

The local application is a private React 19/TypeScript/Vite frontend with Express 4, legacy MongoDB-backed OMS/WMS routes, and a separate PostgreSQL Central Inventory ledger and worker. `package.json`, `README.md`, `inventory/ledger.js`, `inventory/receipt-bridge.js`, and `db/migrations/001_central_inventory.sql` were inspected. The README describes Shopify order observation as read-only; it does not establish production provider publishing or hosted verification. The project already has isolated Node verifier scripts and a local disposable-store harness, but historical PASS results remain bounded by their dated evidence reports.

## Research boundary

URLs above point to moving branches as they existed on review date. No repositories were cloned, built, benchmarked, or security-audited for this report. Test files/directories were inspected as source; upstream test suites were not run.
