## Decision for this checkout

R-01 learns permission/channel checks and explicit actor/reason fields, while preserving stronger local dispatched-quantity and replay boundaries (LOC-005/006). R-03 keeps local transactional outbox and uncertainty fencing (LOC-007/019): the upstream on_commit callback and later delivery persistence are not grounds to replace it. R-06 distinguishes commercial return/refund from physical receiving and storage custody. R-04 keeps provider-specific rate-limit handling; this sender's 4xx policy is inappropriate as a generic marketplace policy.

Remaining evidence limits: real gateway idempotency and refund reconciliation, duplicate/mixed-order line IDs, concurrent return validation, process crash before callback/enqueue, subscription/deferred payload branches. These are bounded unknowns and do not weaken the documented observed mechanisms. No current exploitable vulnerability is claimed.
