# Database authority matrix — initial current-state evidence (2026-10-08)

This matrix records observed code ownership and proposed direction. A proposal is not a migration approval or evidence that configured data has moved. Existing Mongo documents and PostgreSQL rows must not be rewritten or dual-written by inference. Tenant and external contract details remain to be established per workflow.

The [source inventory](hardening/MONGO_MODULE_OWNERSHIP_REVIEW.md) enumerates all 133 registry modules referencing 61 Mongo collections and 57 declared PostgreSQL `ci_` tables. Every module remains marked pending field-level review there; the major-entity rows below identify the decisions and overlaps supported by current source. The inventory can be regenerated with `node scripts/audit-database-authority.mjs` without connecting to either database.
